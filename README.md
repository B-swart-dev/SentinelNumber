# 🔁 Sentinel Number Input System

## Overview
A simple Java Swing application demonstrating the use of a sentinel-controlled loop to collect user input.

The application allows users to continuously enter values until a termination keyword ("exit") is entered.

---

## Features
- Accepts multiple user inputs
- Uses a sentinel value ("exit") to stop input
- Stores values in an ArrayList
- Displays results in a list and dialog

---

## Tech Stack
- Java  
- Java Swing  
- ArrayList  

---

## How to Run
Run:
```bash
SentinelNumber.java
```
